Ghostlight — source code (GPL)

The live Ghostlight site serves a modified build of ScummVM as WebAssembly (scummvm.wasm). ScummVM is licensed under the GNU General Public License, version 3 or later, and so is our modified build. This page carries the corresponding source for the modification, as the GPL requires.

What the modification is

Ghostlight adds a small, self-contained accessibility layer to two of ScummVM's engines: Drascula and Flight of the Amazon Queen (Queen). The served scummvm.wasm contains both modified engines. For each engine it is new code (Drascula: engine/a11y.cpp, engine/a11y.h; Queen: engine/queen/a11y.cpp, engine/queen/a11y.h) plus a short patch that hooks it into that engine's own sources (engine/hooks.patch and engine/queen/hooks.patch). Nothing else in the upstream engines is changed.

The modification source

  • engine/a11y.cpp — the accessibility layer
  • engine/a11y.h — its header
  • engine/hooks.patch — the hooks into ScummVM's Drascula engine
  • engine/queen/a11y.cpp - the Queen accessibility layer
  • engine/queen/a11y.h - its header
  • engine/queen/hooks.patch - the hooks into ScummVM's Queen engine
  • scripts/build-web.sh — the reproducible WebAssembly build script

Upstream ScummVM (the unmodified base)

The build is based on ScummVM at the pinned commit ad351d1e (ad351d1e9d64912c61b4049fe608d003e639b4cc):

  • github.com/scummvm/scummvm @ ad351d1e

Clone it with git clone https://github.com/scummvm/scummvm.git and check out that commit.

How to rebuild the wasm from this source

  1. Check out ScummVM at commit ad351d1e into vendor/scummvm.
  2. Copy a11y.cpp and a11y.h into engines/drascula/ and add a11y.o to that engine's module.mk.
  3. Copy queen/a11y.cpp and queen/a11y.h into engines/queen/ and add a11y.o to that engine's module.mk.
  4. Apply hooks.patch to the ScummVM tree (git apply hooks.patch), then apply queen/hooks.patch the same way.
  5. Configure with --enable-engine=drascula,queen and build with ScummVM's Emscripten port (both engines, Ogg/Vorbis on), then make dist-emscripten.

build-web.sh above does all of this automatically. In short: 

scripts/fetch.sh        # fetch ScummVM @ ad351d1e into vendor/
scripts/build-web.sh    # copy engine/ in, apply both hooks.patch files, build scummvm.wasm
