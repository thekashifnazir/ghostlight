# Ghost hint audio cache

Content-addressed whispers of the pack's hint lines, one `<key>.mp3` per line,
where `<key>` is `cacheKey(text, voiceId, modelId)` (see `../cache.ts`).

These files are generated by `scripts/gen-voice.ts` with ElevenLabs (voice
Alice `nbk2esDn4RRk4cVDdoiE`, model `eleven_v4`) and are committed, because the
hint lines are the project's own authored content, not game data.

The cache lives under `src/` (not a top-level `public/`) because the Vite config
sets `root: "src"` and `publicDir: false`; `../audio.ts` resolves these files to
hashed asset URLs with `import.meta.glob('./ghost/*.mp3', { query: '?url' })`,
so they are served in dev and copied into `dist/` with no config change.

A missing file is not an error: playback falls back silently to the live-region
text, which always carries the full hint on its own.
