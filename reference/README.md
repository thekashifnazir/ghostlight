# reference/

Inputs from the private prep phase (6 Nov 2026), done in Claude Code before Kiro credits arrived:
research, throwaway spikes and their findings. **No spike code is copied here.** Everything in
this repo's `src/` is written in Kiro from these findings.

- `design.md`: the product design (intent, users, goals, non-goals, architecture, Kiro plan)
- `spike-results.md` and `spikes/*.md`: what each spike proved, gotchas found
- `census.json`: rooms, hotspots, exits, items, flags and text counts for Drascula
- `pack-draft/`: v0 accessibility pack format, schema and a hand-drafted chapter 1-2 pack (to be reviewed and rebuilt through the survey crew)
- `research/`: what blind players ask for, prior art, extra features
