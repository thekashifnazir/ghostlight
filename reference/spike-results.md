## Facts found so far

- **6 Nov:** the English freeware release is **text only**: the readme says only the Spanish version has full voice-overs. Its `audio/` folder is 31 music tracks. So pre-recording the English script would give the first voiced English Drascula, which the licence allows (clause 4: modify, distribute with a notice).
- **6 Nov:** English game text is 774 strings, about 37,400 characters (counted from `devtools/create_drascula/staticdata.h`). **Corrected 6 Nov (spike 05):** that count included `_textd1`, 11 lip-sync code strings. Real text is 763 strings, 36,243 characters, plus 52 conversation choices (2,004 chars) in `op_*.cal` that duplicate `_text` lines.
- **6 Nov:** per room, the engine loads object number, name, hotspot rectangle, walk-to point, visible flag, door flag and destination (`engines/drascula/rooms.cpp`, `drascula.h`). Inventory is `inventoryObjects[43]`, progress is `flags[NUM_FLAGS]`.
